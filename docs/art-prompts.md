# Art still to make — prompts and file names

The game shows painted art from `assets/` wherever it exists, and its own
drawn art everywhere else. These are the pictures still missing. Make each
one (ChatGPT, Canva or anything we have commercial rights to), save it with
**exactly** the file name shown, and either attach it in the Claude chat or
upload it to the `assets/` folder on GitHub (Add file → Upload files). Then
ask Claude to "add the new art" — it resizes, compresses and wires them in.

**Style line to add to every prompt:**
> Stylised synthwave graphic-novel digital painting, night, neon magenta and
> cyan lighting, cinematic, high contrast. No text, no letters, no logos, no
> real car brands, no real people.
